Alle Aufnahmen sind 1400×900 Pixel groß – das entspricht der Standardgröße des
Anwendungsfensters auf einem Bildschirm ohne Skalierung.

## Neue Aufnahmen machen

- Fensterbreite 1400 px, als PNG speichern
- Auf einem Bildschirm mit Skalierung (125 %, 150 % …) wird die Aufnahme sonst
  unscharf hochgerechnet. Entweder den Prozess DPI-bewusst starten und die
  Tk-Skalierung auf `96/72` festnageln, oder auf einem Bildschirm ohne
  Skalierung aufnehmen.
- **Keine persönlichen Dateipfade, Ordnernamen oder privaten Bilder im Bild.**
  Die vorhandenen Aufnahmen benutzen einen neutralen Beispielordner mit
  erzeugten Bildern.
- Dateigröße nach Möglichkeit unter 500 kB halten
